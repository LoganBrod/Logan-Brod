# Course B

Rename this folder and the `course:` line above to the real class name, for
example `AP Biology`. Keep them identical: the brain matches notes to courses
by this name.

Leave `units: []` empty if you do not know the units yet. The brain fills it
in: a syllabus dropped in the inbox teaches the course its unit list, and a
note that fits no listed unit creates one. Or type them yourself, one per
line, as `  - Unit 01 - Name`.

`study_hours` is how long the planner books for each kind of assessment. Guess
now, adjust after the first test.
