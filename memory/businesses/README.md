# Businesses

One file per business, named as a slug: `acme-widgets.md`.

The `get_business` MCP tool resolves a name to `memory/businesses/<slug>.md`,
so the filename is the lookup key — keep slugs lowercase and hyphenated.

Each file should carry, at minimum:

```
# <Business name>

**What it is:**
**Who it's for:**
**Stage:**
**Biggest bottleneck right now:**
**Already tried, didn't work:**
```

Files here are written from what Logan actually said in interview. Nothing in
this folder should be inferred or invented.
